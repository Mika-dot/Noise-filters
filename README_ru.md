# Noise-filters

> Наглядный и воспроизводимый справочник по цифровой фильтрации показаний
> датчиков, промышленной телеметрии и сигналов микроконтроллеров.

[English README](README.md) · [Интерактивная демонстрация](docs/playground/index.html) · [Исходные данные метрик](docs/assets/benchmarks/quality-metrics.csv)

В репозитории сохранены исходные C#-алгоритмы, добавлен расширенный набор
фильтров и реальный стенд, который прогоняет все алгоритмы на одном сигнале.

## Симуляция

Это не нарисованная вручную схема. В эксперименте используется сигнал из 720
отсчётов: две периодические составляющие, ступенчатое изменение, медленный
дрейф, белый гауссов шум (`σ = 3.2`) и девять положительных/отрицательных
импульсных выбросов. Фиксированный seed: `20260824`.

![Все фильтры на одном зашумлённом сигнале](docs/assets/benchmarks/signal-comparison.png)

### Подавление выбросов

Бегущее среднее размазывает импульс по ширине окна. Медианный и Hampel-фильтры
распознают его как аномальное измерение и почти не искажают соседние отсчёты.

![Сравнение подавления выбросов](docs/assets/benchmarks/impulse-rejection.png)

### Реакция на ступеньку

Чем сильнее сглаживание, тем больше задержка реакции на реальное изменение
процесса. Deadband пропускает изменение только после пересечения порога.

![Переходная характеристика](docs/assets/benchmarks/step-response.png)

## Измеренное качество

RMSE и MAE рассчитаны относительно известного чистого сигнала после 20
прогревочных отсчётов. RMSE/MAE — меньше лучше, прирост SNR — больше лучше.

![Метрики качества фильтров](docs/assets/benchmarks/quality-metrics.png)

| Фильтр | RMSE | MAE | Прирост SNR | Оптимальная задержка |
|---|---:|---:|---:|---:|
| **Median** | **1,45** | **1,13** | **+10,00 dB** | 0 отсчётов |
| Weighted Average | 1,72 | 1,23 | +8,51 dB | 0 отсчётов |
| Gaussian | 1,79 | 1,27 | +8,19 dB | 0 отсчётов |
| Simple Kalman | 1,89 | 1,45 | +7,72 dB | 3 отсчёта |
| Savitzky-Golay | 2,31 | 1,67 | +5,95 dB | 0 отсчётов |
| Moving Average | 2,31 | 1,79 | +5,95 dB | 4 отсчёта |
| Exponential | 2,65 | 2,13 | +4,77 dB | 6 отсчётов |
| Hampel | 3,19 | 2,54 | +3,16 dB | 0 отсчётов |
| Deadband | 4,62 | 3,07 | −0,05 dB | 0 отсчётов |
| Alpha-Beta | 4,73 | 4,01 | −0,27 dB | 13 отсчётов |

Медианный фильтр победил именно в этом смешанном сценарии, потому что в сигнале
есть сильные импульсные выбросы. Это не означает, что он всегда лучший.
Alpha-Beta требует корректной модели движения, а Deadband предназначен для
подавления дребезга в управлении, а не для восстановления аналоговой формы.

## Быстрый выбор фильтра

| Задача | Что попробовать первым | Компромисс |
|---|---|---|
| Редкие выбросы и ошибочные измерения | Hampel или Median | Median может сгладить узкие полезные пики |
| Белый высокочастотный шум | Gaussian или Weighted Average | Симметричному окну нужны будущие отсчёты |
| Потоковый датчик с минимумом памяти | Exponential Average | Фазовая задержка |
| Известная динамическая модель | Kalman | Требуется настройка шумов и модели |
| Сохранение формы пиков | Savitzky-Golay | Чувствителен к большим выбросам |
| Дребезг реле/регулятора | Deadband | Ступенчатый выходной сигнал |
| Оценка положения и скорости | Alpha-Beta | Ошибка модели даёт запаздывание |

## Реализованные алгоритмы

- среднее и растянутая выборка;
- бегущее и экспоненциальное среднее;
- адаптивный коэффициент;
- медианный фильтр;
- метод наименьших квадратов;
- Simple Kalman и Alpha-Beta;
- Weighted Moving Average и Gaussian;
- Hampel;
- настоящий Savitzky-Golay с локальным полиномом;
- Deadband и Median Absolute Deviation.

## Как пересоздать графики

```bash
python3 -m pip install numpy matplotlib
python3 tools/generate_benchmarks.py
```

Скрипт сохраняет PNG и исходные CSV в `docs/assets/benchmarks/`. Сигнал,
параметры, позиции выбросов и seed зафиксированы, поэтому метрики
воспроизводятся.

## Пример C#

```csharp
using Filters;

double[] gaussian = AdvancedFilters.GaussianFilter(samples, size: 9, sigma: 2.0);
double[] hampel = AdvancedFilters.HampelFilter(samples, window: 4, threshold: 3.0);
double[] shaped = AdvancedFilters.SavitzkyGolay(samples, window: 9, polynomialOrder: 3);
double[] stable = AdvancedFilters.Deadband(samples, limit: 2.0);
```

## Структура

```text
Filters/Filters/filtration.cs          исходные алгоритмы
Filters/Filters/AdvancedFilters.cs     расширенные фильтры
tools/generate_benchmarks.py           воспроизводимая симуляция
docs/assets/benchmarks/                графики и CSV
docs/playground/index.html             интерактивная демонстрация
Filter in charts/                      исторические графики
```

Параметры фильтра нужно подбирать под частоту дискретизации, тип шума и физику
конкретного процесса. Один алгоритм не может быть лучшим для всех сигналов.
